# DEAD ZONE

Top-down survival shooter for Android.

The first playable build contains a self-contained map, touch movement, zombies, melee combat, pistol shooting, loot crates, survival stats, backpack inventory, day/night and death/restart.

No remote assets and no network connection are required.

GitHub Actions builds app-debug.apk and publishes it as an artifact.

Application ID: pl.tupsonik.deadzone
