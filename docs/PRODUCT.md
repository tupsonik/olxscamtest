# Nie Wtop — MVP

## Core flow
1. User pastes an offer URL or shares a screenshot.
2. App extracts available offer information.
3. Analysis checks price, seller signals, domain/payment red flags and duplicated-looking content.
4. App presents evidence and uncertainty rather than claiming certainty.

## Screens
- Home
- Analyze
- Result
- History
- Settings

## Product principle
A risk indicator is not proof of fraud. The app explains concrete signals so the user can decide what to do.
